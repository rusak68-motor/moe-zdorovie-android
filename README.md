# Моё здоровье
Пробная Android-версия для Motorola Razr 50.

Разделы: давление, вода, питание, отметки о лекарствах, журнал, текстовый отчёт.
Все пользовательские записи сохраняются только локально в WebView (localStorage); публичный репозиторий не содержит медицинских данных.

**Ограничения:** Автоматическое подключение Garmin, Fitbit и Wellue ещё не реализовано. Нет фоновых напоминаний, PDF и медицинской диагностики. Не используйте приложение как единственное средство напоминания о назначенных препаратах.

Для APK откройте Actions → Build APK → последний успешный запуск → Artifacts → Moe-Zdorovie-0.3-APK.
